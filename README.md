# Uso da Inteligência Artificial nas Universidades

Este projeto apresenta uma página simples em HTML e CSS sobre o uso da Inteligência Artificial (IA) no ambiente universitário. O objetivo é demonstrar como a IA pode contribuir com ensino, pesquisa, inovação e aprendizagem personalizada.

## 🎯 Objetivo

Explicar de forma visual e acessível como a Inteligência Artificial está sendo aplicada nas universidades, destacando seus benefícios e impactos no processo acadêmico.

## 📄 Conteúdo da página

A página inclui:

- Introdução ao tema
- Benefícios da IA na educação superior
- Seção com aplicações em pesquisa, ensino e inovação
- Tabela com os nomes dos alunos responsáveis pela pesquisa
- Layout responsivo para diferentes tamanhos de tela
